# cad-viewer

`<cad-viewer>` is a web component for showing GLB/glTF models on a page:
orbit, zoom, flick to spin, and a scrubbable **exploded view** authored as
animation clips in the model itself. It's a single file with no framework and no build step, and
three.js is its only dependency.

```html
<script type="module" src="https://cdn.jsdelivr.net/gh/cobylai/cad-viewer@v1.0.0/dist/cad-viewer.cdn.js"></script>

<cad-viewer src="model.glb" alt="Gearbox assembly" autoplay></cad-viewer>
```

Open `demo/index.html` through any static server (`python3 -m http.server`,
then `/demo/`) to try it. The demo model is generated by
`scripts/make-demo-cubes.py`, a small example of writing explode clips by hand.

## Features

- **Scroll-safe by default.** A transparent overlay keeps the viewer from
  capturing scroll and touch while a reader is passing by. Click (or focus and
  press Enter) to interact. It locks again after 30 s idle or a click elsewhere.
- **Flick to spin.** Release a drag with some speed and the model keeps
  turning at that speed. Very fast flicks ease back down to 15 RPM.
- **Exploded views** come from the model's own animation clips, so the
  explode can be as choreographed as you like. The slider scrubs them, and ▶
  ping-pongs them.
- **Settles back on its own.** Auto-rotation resumes 15 s after the last
  interaction, and the zoom eases back to its framing after 30 s.
- **Cheap when off screen.** It renders only while on or near the screen,
  frees GPU memory when removed, and recovers if the browser drops its WebGL
  context.
- **Draco, Meshopt and KTX2** compressed models load out of the box.
- **Keyboard:** arrows orbit, `+`/`-` zoom, Escape hands control back to the page.
- **Themeable** with CSS custom properties and `::part()`, inside a shadow root
  so page styles don't leak in.

## Install

**Plain HTML.** Use `dist/cad-viewer.cdn.js`, which imports three.js from
jsDelivr. It doesn't need an import map. The URL above is pinned to a release;
change the tag to upgrade.

**With a bundler.** `cad-viewer.js` imports `three` and `three/addons/...` as
bare specifiers, so it shares your app's three.js:

```sh
npm install three github:cobylai/cad-viewer
```

```js
import 'cad-viewer';                        // registers <cad-viewer>
import { CadViewer } from 'cad-viewer';     // the class, if you need it
```

Tested with three.js r168.

## Attributes

Every attribute can be changed at any time and takes effect immediately.

| Attribute | Default | |
|---|---|---|
| `src` | | GLB/glTF URL. Also settable as the `src` property. |
| `alt` | `3D model` | Accessible name. |
| `aspect-ratio` | `16/9` | Any CSS ratio (`4/3`, `1`, `2.35`). |
| `rotation-speed` | `1` | Auto-rotate speed in RPM. Negative spins the other way; `0` stops. |
| `camera-tilt` | ~17 | Camera elevation above the horizon, in degrees (0–89). |
| `default-zoom` | `1` | Framing multiplier: above 1 is closer, below 1 further. |
| `camera-offset-y` | `0` | Moves the model up (+) or down (−) in the frame, as a fraction of its size. |
| `fit-explode` | | Frame the fully exploded model, not just the assembled one. |
| `flip` | | Rotate the model 180° about X, for upside-down exports. |
| `exposure` | `1` | Tone-mapping exposure (brightness). |
| `studio-light` | | Image-based room lighting, for dark or glossy models. |
| `autoplay` | | Start the explode animation on load. |
| `animation-speed` | `12` | Seconds per full explode + collapse cycle. |
| `no-explode` | | Ignore the model's animations; hide the explode controls. |
| `no-interact` | | Display-only turntable: no overlay or controls, and pointer events pass through. |
| `lock-zoom` | | Disable wheel, pinch and key zoom. |
| `no-auto-resume` | | Don't resume auto-rotation after interaction. |
| `no-zoom-restore` | | Don't ease the zoom back after interaction. |
| `draco-decoder-path` | jsDelivr | Self-host the Draco decoder. Read once. |
| `ktx2-transcoder-path` | jsDelivr | Self-host the Basis transcoder. Read once. |

## Events

| Event | `detail` |
|---|---|
| `load` | `{ scene, animations }` once the model is in place |
| `progress` | `{ loaded, total }` while downloading |
| `error` | `{ error }` if loading fails; the viewer also shows a message |

## Styling

The background is plain CSS, so it follows whatever theme the page uses:

```css
cad-viewer {
  --cad-viewer-bg: #fbf8ef;             /* frame background (default transparent) */
  --cad-viewer-fg: #111;                /* text, controls (default currentColor) */
  --cad-viewer-border: 1px solid #111;
  --cad-viewer-radius: 4px;
  --cad-viewer-hint-bg: rgba(0,0,0,.1); /* overlay tint while pressed */
}
[data-theme="dark"] cad-viewer { --cad-viewer-bg: #161616; --cad-viewer-fg: #eee; }
```

For anything else, the parts are `frame`, `canvas`, `overlay`, `status` and
`controls`, e.g. `cad-viewer::part(controls) { justify-content: center; }`.

## Authoring an exploded view

The viewer doesn't compute explode directions. It plays what the file carries,
which leaves you in full control:

1. Keyframe each part's position (and rotation, if you like) in Blender from
   assembled to exploded.
2. Export GLB with **Animation** enabled. Each object's action becomes a clip.
3. The slider's 0–1 maps onto the longest clip. Clips can start at different
   times, so staggered explosions are just keyframe offsets.

## Getting CAD into it

Export your model as a STEP file (Fusion, Onshape, SolidWorks and FreeCAD all
can). Then convert it to GLB with free tools. [cascadio](https://pypi.org/project/cascadio/),
a Python package built on OpenCascade, converts STEP to GLB and keeps colours.
Blender is there if you want to hand-tune the explode.

The easiest route is to let Claude do it. Install
[Claude Code](https://claude.com/claude-code) and Python, put your STEP file in a
folder, open Claude Code there, and paste:

```text
I have model.step in this folder. Install cascadio and pygltflib with pip.
Convert the STEP to model.glb with cascadio, keeping the colours. Wrap the scene
in a root node rotated -90 degrees about X, since STEP is Z-up and glTF is Y-up.
cascadio makes every material metallic, which renders near-black, so set metal
parts (pins, screws, shields) to metallic 1, roughness 0.35, and everything else
to metallic 0, roughness 0.55. Then add an exploded view: one animation clip per
part, moving it outward from the centre of the assembly, staggered from the
inside out, about 1.5 seconds in total. Check the result loads and tell me which
parts you treated as metal.
```

## Notes

- Browsers cap live WebGL contexts (roughly 8–16). A handful of viewers on one
  page is fine. Beyond that, the browser drops the oldest context, and that viewer
  rebuilds when it scrolls back into view.
- Needs ES modules and `aspect-ratio` (Chrome 89+, Firefox 89+, Safari 15+).
